## Projeto em destaque

### Evelin Boutique Delivery

Catálogo Web desenvolvido para uma loja de moda feminina utilizando **HTML, CSS e JavaScript puro**.

Principais funcionalidades:

- catálogo dinâmico com produtos;
- busca por nome e categoria;
- filtros por categoria e tamanho;
- ordenação de produtos;
- favoritos;
- sacola de orçamento;
- produtos vistos recentemente;
- detalhes dos produtos;
- persistência de dados com `localStorage`;
- compartilhamento de produtos;
- integração com WhatsApp;
- layout responsivo;
- cuidados de acessibilidade e navegação por teclado.

**Tecnologias:** HTML, CSS, JavaScript, Git e GitHub.
